## 2. Pull du code

```bash
cd ~/zolaashe/zola-ashe-backend
git fetch origin
git log HEAD..origin/main --oneline    # vérifier ce qu'on va prendre
git pull --ff-only origin main
```

Attendu : au moins le commit `f6e6734 feat: livrer 12 items du rapport de test`.

---

## 3. Rebuild + up

```bash
docker compose -f docker-compose.prod.yml build backend
docker compose -f docker-compose.prod.yml up -d --pull=never --force-recreate backend
```

> `--pull=never` évite d'écraser l'image locale fraîchement buildée
> (cf. `FIX_REDEPLOY_PULL_NEVER.md`).

## 8. Vérifications fonctionnelles côté métier

- [ ] Un membre `ACTIF` sans branche → PDF branche FEMME renvoie **403**.
- [ ] Un membre `ACTIF` avec `access_levels=["FEMME"]` → PDF branche FEMME renvoie **200 + presigned URL MinIO**.
- [ ] Initier un paiement `kind=ANNUEL` → webhook Swinmo simulé → l'abonnement `MEMBRE` gagne **12 × période** mois.
- [ ] Action admin **"warn"** sur un user → l'user reçoit email + notification in-app (+ WhatsApp si template `warn_notification` déjà approuvé côté provider).
- [ ] Admin dashboard : `?start_date=2026-01-01&end_date=2026-06-30` doit renvoyer les mêmes chiffres que `?date_from=...&date_to=...`.
- [ ] Revenus mensuels : `/api/admin/finance/monthly-revenue/` renvoie **exactement 12 points**.
